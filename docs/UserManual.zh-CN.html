Tom Shaders X 用户手册

适用：Tom Shaders X 0.4.0，Koikatsu Sunshine，Unity 2019.4 Built-in Forward。 配套：Hair Feather 0.3.0；Tom Lighting Probes 0.2.1；SkinX Face SDF 头骨方向插件 0.1.1；Tessellation Bounds 0.1.1。发布包包含独立 Tess 版本，但不代表新增游戏内验收或性能认证。本文以 ME 中不带前导下划线的参数名为准。

本次收尾只验证代码、ME 元数据和 Unity 渲染，不包含新一轮游戏内验收或全角色性能认证。 展示球是可复现的功能示例，不是自动应用到角色上的默认预设。

1. 安装与选择

主 zipmod 放入游戏的 mods 目录，由 Sideloader / MaterialEditor 注册材质。使用分离后的 V+ LTS，可以与 X 系列共存；不要同时安装仍注册同名 tom/* 的旧合并包。

Shader 用途与区别
tom/MainOpaqueX 通用不透明或镂空表面；不是半透明玻璃
tom/MainAlphaX 常规透明表面；可选 DepthPrepass，默认关闭
tom/MainAlphaXBackFront 背面、正面分层绘制的透明壳；不解决任意交叉网格排序
tom/MainAlphaX2Pass 旧深度预写兼容入口；不是 BackFront，不建议作为新材质首选
tom/HairX 头发镂空、各向异性高光、额前头发 stencil 透明及可选羽化
tom/EyeWX 眼白、眼线等眼部表面，cutout 与 stencil writer；不自动识别网格角色
tom/EyeX 虹膜与瞳孔；局部折射、浅层视差、深度图、可选 RGB 色散
tom/SkinX 脸部与身体共用；保留游戏皮肤、叠加层、服装遮罩和液体约定

tom/SkinXTess SkinX 的独立 D3D11 细分与真实位移版本，保留脸部／身体层与 UV

只使用一般表面、Clearcoat 或 EyeX 光学不需要额外插件。HairX 的 Feather 模式需要 TomHairFeather.dll 和同目录 hairx-feather.unity3d；缺少支持时回退硬边，不会自动得到柔化 stencil。

工作室探针物品另装 Tom Lighting Probes 的 zipmod，并安装 KKS_TomProbe.dll 与 TomProbe.Runtime.dll 到 BepInEx/plugins/TomProbe。不要保留多份旧 DLL。控制 shader 只给探针物品用，不应替换角色材质。

2. 通用调节顺序

  1. 选择正确的 shader，保留游戏管理的贴图、颜色和 UV 参数。切换前保留角色卡或场景副本。
  2. 关闭所有 Debug View，确认主贴图、透明度和裁剪正常，再调风格。
  3. 先调整 Toon Shading 与 Lighting，建立明暗关系。
  4. 再调整 Material / Direct Specular，区分普通高光与 Toon 高光。
  5. 选择 Environment Reflection 或 MatCap；最后按需加入 Clearcoat、Rim 和 Outline。
  6. 眼睛、头发、皮肤的专属功能在通用底层之上调节，不需要推翻 stencil 或透明度设置。

适用的底材 shader 共享公共光照基线和调节分类，但同名不代表所有系列的类型、范围与默认值完全相同：LiquidX 负责薄液体覆盖层的颜料，Skin 与 Eye 也保留各自的游戏兼容和光学差异。各 Tess 版本继承普通父版本的控件与光照，再增加几何控制。游戏兼容别名有意保留原拼写，包括 SpeclarHeight。ME 将部分枚举显示成数值滑条时，请输入说明中的整数，不要停在两个模式之间；MatCapBlendMode 则明确支持连续混合，不属于枚举。贴图、数值、颜色仍使用 ME 原有控件；本文不假定所有版本都支持自定义下拉菜单。

IndirectDiffuseIntensity 新材质默认 0.25。它只缩放间接漫射，不缩放直接灯、反射或 Clearcoat。已存储的旧值不会自动改成 0.25。Maker 中皮肤显得发白时，应先检查间接光和曝光，不要立即重命名游戏颜色参数。

3. 光照与风格

Toon Shading：UseRamp 混合连续漫反射与 Toon 明暗。RampMode=0 使用程序化阈值，1 使用 RampTex 的 R 通道；SecondaryRamp 通过 LayerMask R 和 SecondaryToneStrength 混合。RampTex 是明暗曲线，不是直接彩色渐变染色。

Toon 法线与柔和边界：MainOpaqueX、三个 Alpha 变体、HairX、EyeWX、EyeX 和 SkinX 共享这条路径。ToonNormalInfluence（0..1，默认 1）只控制主法线对直接 Toon 漫反射的影响；ToonDetailNormalInfluence（0..1，默认 1）独立控制细节法线。SkinX 复用现有 SkinDiffuseNormalDetail，并保留其原有的漫反射/SH 行为，不增加重复滑条。主法线影响为 0 不会同时关闭细节输入。NormalMapScale/DetailNormalMapScale 仍决定源法线强度。高光、环境反射和 Clearcoat 保留完整法线；EyeX 的 Toon 法线跟随折射后的虹膜采样，但这些控制不改变折射位移。

Toon 漫反射改为单层网格明暗交界过渡，由 ToonSoftness 控制，不再额外乘一次贴图法线的窄交界。NormalHorizonFade 仍保护连续漫反射、高光、Clearcoat 和液体。ToonAA（0..2，默认 1）为程序化明暗边界与网格交界提供基于屏幕导数的最小过渡宽度；贴图 Ramp 保留自身采样过滤。它不能修复压缩方块，也不会抹掉大尺度的凹凸。皮肤可从 ToonNormalInfluence=0.25、SkinDiffuseNormalDetail=0.1、ToonSoftness=0.12 开始调节，不需要关闭全局法线来换取干净的明暗边界。

Toon 最低明暗响应：ToonMinLighting（0..1，默认 0.15；设为 0 可关闭）在网格背光限制和投影之后重映射主光 Toon 漫反射：u' = m + (1-m)*u。自投影和外部遮挡中的暗部都会被抬起，全亮端不变。建议先把 ToonShadeColor 的 A 设为 0，再从 0.1..0.25 调起。配套材质预设使用 0.15；显式保存的值不变，未保存此参数的旧材质会继承新默认值。这是归一化明暗响应下限，不是最终像素 RGB 下限，也不是 GI 或自发光。底色、主光颜色/强度、距离/cookie、漫反射材质权重及后续涂层/MatCap 衰减仍有效；没有主光不会凭空发亮。UseRamp=0 时禁用，部分 UseRamp 按比例混合。只在 Base 计算一次并遵循烘焙主光归属，不改变连续漫反射、附加灯、SH、高光和反射波瓣。ToonShadeLevel 仍控制背光和投影之前的程序化 Ramp 暗端。

Toon 暗部颜色：ToonShadeColor 由 ToonDarkFillColor 改名，原有可选彩色补光算法不变。RGB 与底色相乘，A 是补光强度，不是表面透明度；默认 RGB=(0.35,0.35,0.35)、A=0。它不是新下限的染色参数；要提亮完全自遮挡的背光面，应使用 ToonMinLighting，而不是继续增大这个颜色。

改名兼容性：Shader 和 Material Editor 的实际属性 ID 已改为 ToonShadeColor。Unity 构建会迁移项目发布材质中的保存值，且不会覆盖已明确保存的新属性。游戏旧人物卡/材质编辑中以 ToonDarkFillColor 保存的值无法仅靠 shader 自动迁移，需要把原 RGBA 重新填写到 ToonShadeColor。没有修改游戏文件或增加运行时迁移插件。

补光跟随 ForwardBase 主光颜色、MainLightIntensity、距离/cookie 衰减及真实投影遮挡，即使 ShadowStrength 绕过普通漫反射投影，补光仍保留物理遮挡。没有主光或 UseRamp=0 时无补光；只在 Base 计算一次，不在 ForwardAdd 重复叠加，并遵循烘焙主光的归属。金属度和可选漫反射能量抑制仍有效。它是主光驱动的艺术补光，不是自发光、真实透射或 SSS。ShadowColor 和间接光默认值 0.25 不变。

Clearcoat 与集成透明液体把彩色补光和下限增量作为宽分布的底材照明进行衰减，不会当成背面入射的高光光线再次归零；实际反射波瓣和背光保护不变。有色液体仍可替换底材贡献。独立 LiquidX 保留已验收的染色路径，不增加这些底材控制。下限默认 0.15，设为 0 可关闭提亮，不覆盖明确保存的参数。

阴影：ShadowStrength 调漫反射阴影参与度；ShadowRemapStrength / Threshold / Softness 重映射阴影可见度。UseRampForShadows 控制阴影进入 Toon 曲线。外部遮挡与曲面自身背光不是同一件事。Clearcoat 直接高光仍受物理阴影约束，不应把它当作无阴影发光。

SkinX 斜光投影：SkinX 及其配套材质现在默认 UseRampForShadows=0。表面明暗仍使用 Toon，但投影可见度在其后相乘，不再同时跨越 Toon 阈值。设为 1 可恢复原路由；不迁移场景或人物卡中明确保存的值，其他 shader 系列的默认值不变。ToonMinLighting 保持 0.15。斜光自投影建议从光源的 Soft Shadows（软阴影） 和 ShadowRemapStrength=0 开始；ToonSoftness、ShadowSoftness 都不能代替引擎阴影采样过滤。Shader 不会强改场景光源或阴影质量。原始阴影贴图的条纹仍可能存在，尤其在 Hard Shadows 下；分离 Ramp 不等于替换阴影过滤算法。仅在需要时分别调整光源 Bias 与 Normal Bias，并检查鼻子、接触处和薄片外部投影。过大的 Bias 或 ShadowOffset 会造成阴影脱离或丢失，本次不提高这些默认值。

直接高光：SpecularStrength 是强度，Roughness 是连续高光粗糙度，SpecularSize 是 Toon 高光大小，两者不互相替代。SpecularIOR/FresnelStrength 控制底层介质响应；Metallic 增大时底层漫反射减少。SpecularAA 用于缓和法线与高光边缘闪烁，不能替代所有时域抗锯齿。

独立高光法线：SpecularNormalInfluence / SpecularDetailNormalInfluence 分别控制干燥底材直接 GGX 与 Toon 高光的主法线、细节法线影响，范围 0..1，默认均为 1，Base 与 ForwardAdd 一致生效。0 只去掉对应输入，两项都为 0 时使用网格法线。HairX 继续使用已有 HairSpecularNormalInfluence / HairSpecularDetailNormalInfluence，对双瓣只应用一次，不叠加第二组共享控制。AA 跟随选定高光法线，几何朝光保护和正常投影仍保留。不会改变漫反射/SH、环境反射、MatCap、Clearcoat 或液体层；全局法线强度仍决定输入强度。EyeX 使用折射后的虹膜法线样本，AA 保留折射前表面足迹。默认 1/1 保持旧材质效果，不增加贴图采样。

多灯：MainLightIntensity / AdditionalLightIntensity 分别调主灯和逐像素附加灯。直接漫射、高光与 Clearcoat 会响应附加灯；SH、环境反射、加法 MatCap、Rim、发光不逐灯重复添加。乘法 MatCap 仍调制各灯的漫反射。

间接漫射：LightProbeBlend 从 AmbientColor 过渡到 Unity 的 SH/Light Probe 路径；CustomSHVolumeBlend 控制已就绪的自定义 SH Volume。IndirectToonBlend 可风格化间接明暗，但不能凭空补出方向信息。没有就绪的 Volume 时保留内置间接光路径。

环境反射：ReflectionMode：0 关闭，1 MatCap，2 环境，3 两者。环境模式需要可用的探针或天空反射；EnvironmentIntensity、Roughness、ToonBlend 分别控制强度、模糊和风格化。默认 UseMaterialRoughnessForEnvironment=1 时，环境采用材质粗糙度，独立 EnvironmentRoughness 不接管。Box Projection 适合有限室内空间，但不是光线追踪。

MatCap：视角空间的二维外观贴图，不是场景实时反射。MatCapBlendMode 现在是连续 0..1 混合：0 保留原 Multiply，1 保留原 Add，中间值插值两种完整合成结果，不会把两层全强度叠加。属性名及默认值 1 不变，旧材质保存的 0／1 端点保持原外观；原先保存的枚举小数现在产生真实混合，不再按 0.5 硬切。MatCapNormalSource：0 网格法线，1 主法线，2 主法线加细节。

MatCapColor 默认白色 RGBA (1,1,1,1)。RGB 乘到 MatCap 采样颜色上；A 是独立的 0..1 整层权重，0 回到无 MatCap，1 保留完整权重。A 淡化的是原强度整形后的结果，因此 Multiply 保留旧强度的饱和规则，Add 保留原来的非饱和强度。A 不改变模型透明度、裁剪或投影，MatCap 贴图自身的 A 仍不使用。RGB 黑色不等于关闭，在 Multiply 下可能压暗底材；关闭请用 A=0 或 MatCapIntensity=0。已明确保存的颜色值不会被重置。

Multiply 部分仍一致调制 Base 和每个 ForwardAdd 的漫射，Add 部分只在 Base 添加一次。MatCapColor 不直接给高光、环境反射、Clearcoat／液体反射瓣、Rim 或发光染色；保留现有涂层和液体合成关系。每个活跃 Pass 的两部分复用一次 MatCap 采样；纯 Add 在 ForwardAdd 中跳过 MatCap 采样，中间态则需要该 Pass 的乘法路径，不能视为纯 Add 的零成本替代。这些控制覆盖全部 11 个支持 MatCap 的普通／Tess 入口，不给 LiquidX helper 增加 MatCap。

MatCapNormalInfluence / MatCapDetailNormalInfluence 独立控制 MatCap 的主法线与细节法线，范围 0..1，默认均为 1，覆盖包括 HairX 在内的八个底材 shader。保留来源选项：Geometry 忽略两个滑条；MainNormal 只使用主法线滑条，忽略细节；CombinedNormal 使用两项。组合模式下主法线为 0 不会去掉细节，两项都为 0 则使用网格法线。加法 MatCap 和各灯漫反射上的乘法 MatCap 使用同一控制，不影响其他层。EyeX 跟随折射后的法线样本。默认保持原来源和旧材质效果，不覆盖已保存参数。

Rim / Outline / Emission：Rim 是视角边缘项；Outline 是外扩壳轮廓，两者独立。屏幕空间 OutlineWidth 按像素调宽。发光不会自动给周围物体投光。SkinX 的 UV4 用于游戏叠加层，不能再用作外轮廓平滑法线。

4. 贴图通道速查

颜色贴图按颜色导入，数据贴图关闭 sRGB。法线贴图按 Unity 法线贴图方式导入；不要把普通 RGB 法线图、RG 流向图或灰度深度图互换。在 ME 运行时导入时，先确认该版本的导入行为；本次未在游戏里验证它是否保留所有颜色空间设置。

贴图 通道定义
MainTex RGB 颜色；A 覆盖率，具体行为取决于 shader
MaterialMap R 金属、G 粗糙度、B AO、A 直接高光遮罩；UsePackedMaterialMap=1 时接管分离图
LayerMask R 次级 Toon、G Rim、B MatCap、A 环境反射
MetallicMap / RoughnessMap R 乘相应标量；粗糙度之后再加 RoughnessBias
OcclusionMap R AO；白色无遮挡，影响间接项，不直接关闭主灯
SpecularMask R 直接高光，不控制环境、MatCap、Rim；packed 模式忽略此图
ReflectionMask R 公共反射区域，再乘 LayerMask B/A
ClearCoatMap R 涂层权重，G 涂层粗糙度乘数；B/A 不用，白色中性

5. Clearcoat

Clearcoat 是覆盖在底材上的无色介质高光与环境反射层，不是视差。视差改变看到的内部纹理位置，Clearcoat 表达外表面的光泽，因此可以同时启用。

  • ClearCoat=0 关闭；不改变 alpha 或 stencil。
  • ClearCoatRoughness 与底层 Roughness 独立；值越低，高光越集中。
  • ClearCoatIOR 只影响涂层 Fresnel 和分层能量。设为 1 消除涂层反射，不改变 EyeX 视差位移。
  • ClearCoatEnvironmentStrength 独立于底层 ReflectionMode，因此关闭底层反射并不关闭涂层反射。
  • ClearCoatEnergyBlend=0 保留 Toon 漫反射亮度，1 使用分层衰减近似；底层镜面项仍受涂层衰减。
  • ClearCoatNormalSource：0 网格，1 主法线，2 主加细节，3 独立涂层法线。EyeX 的界面法线取自未视差偏移的表面。

涂层很亮时会在视觉上盖住虹膜对比度，但这不等于视差算法被关闭。先关闭涂层或查看 EyeDebugView 的位移图来区分两者。

6. HairX

ME 分类

四个相邻的头发高光分类按「流向 → 主瓣与共用控制 → 副瓣 → 可选局部控制」布置。本次只整理元数据：属性 ID、范围、默认值、保存值和光照计算均不改变。分类内部的行顺序仍可受 ME 按名称／类型排序的设置影响。

Category 参数与作用范围
Hair Direction StrandAngle、StrandDirectionMode、StrandDirectionMap、StrandDirectionBlend，只负责两瓣共用的发丝流向。
Hair Highlight 共用的 HairAnisotropy、HairSpecularNormalInfluence、HairSpecularDetailNormalInfluence、HairHeightAxisAngle；主瓣的 HairPrimaryHeight、HairHighlightShift、HairPrimaryLongitudinalWidth、HairPrimaryAzimuthalWidth。
Hair Secondary Highlight HairSecondaryWeight 及副瓣高度、角度偏移、物理／Toon 形状和染色，包括 HairSecondaryHeight。
Hair Local Controls UseHairHighlightMap、HairHighlightMap、HairPrimaryShiftMapScale、HairSecondaryShiftMapScale；可选，不是 Surface Height 的前置要求。
Environment Reflection HairEnvironmentAnisotropy 并入现有环境反射控制，不再单独设置 Hair Environment 分类。
Direct Specular 强度、颜色、蒙版、投影可见性、Bands、AA 为两瓣共用；SpecularToonBlend／Size／Threshold／Softness 只控制主瓣。
Material 共用的物理粗糙度、贴图、偏置、IOR 与 Fresnel；副瓣再加独立 RoughnessOffset，Toon Size 另行控制。

不再设置独立的 Hair Surface Height 分类：主瓣高度和共用高度轴在 Hair Highlight，副瓣高度在 Hair Secondary Highlight。HairFront 与 Debug 保持独立；Head Band 继续封存和隐藏。

SecondaryWeight=0 时，其余副瓣参数没有可见贡献；UseHairHighlightMap=0 时忽略控制图及局部偏移强度。ShiftMapScale=0 只取消该通道的角度偏移，不取消图中的覆盖蒙版。Toon Size／Threshold／Softness 需要对应 Toon 混合大于零；SecondaryRoughnessOffset 仅影响副瓣中的连续高光部分。这些依赖通过提示说明，不通过重置保存值或新增动态隐藏功能实现。

颜色、流向与高光

ColorMask 遵循 KKS/xukmi 的 RGB 顺序混合：R 将白色混向 Color，再由 G 混向 Color2，最后由 B 混向 Color3；不是权重相加。未指定或黑色蒙版保留贴图颜色；纯红使用 Color，纯白使用 Color3。ColorMask 有独立的平铺和偏移；过滤与寻址模式复用 MainTex，以满足 D3D11 采样器数量限制。BaseColor 保留为额外的整体乘色。继承游戏发色时建议 BaseColor 保持白色；旧 HairX 材质若曾手动染色，可能需要将其恢复白色，避免二次染色。切换 shader 时仍需游戏或 ME 保留原有蒙版和 Color/Color2/Color3 值。

StrandAngle：U 方向为 0°，V 为 90°。StrandDirectionBlend 混合手动方向与线性 RG 流向图（RG*2-1，不是 Unity 法线图）。StrandDirectionMode=0 保留旧版无向轴及符号对齐；模式 1 将箭头视为发根到发梢，按角度插值，反向箭头也有稳定中点。请统一绘制方向，UV 布局不能自动识别发根；零向量回退 StrandAngle。缺少网格切线时只保证有限的回退结果，不保证正确发丝方向。

HairHighlightShift 与 HairSecondaryShift 分别以角度旋转两瓣直接高光框架。正值使高光法线朝正向发丝箭头倾斜，屏幕上亮带的移动方向由几何、光线与视角共同决定，不是世界高度。连续 GGX 与 Toon 高光共享偏移；漫反射、投影和涂层法线仍使用各自框架。Primary/Secondary LongitudinalWidth 与 AzimuthalWidth 分别调整沿发丝与跨发丝的宽度倍率，1 为中性；HairAnisotropy 保留为共同基础长宽比。

HairSecondaryWeight=0 保留单瓣外观。副瓣份额 w 按 (1-w)*主瓣 + w*副瓣 分配现有 SpecularStrength 总强度，并共享 SpecularColor、总蒙版、IOR 和真实光照可见性。副瓣 Size/Threshold/Softness/ToonBlend 塑造 Toon 端点；SecondaryRoughnessOffset 在现有粗糙度贴图之后调整连续 GGX 端点。SpecularBands 与 SpecularAA 共用。SecondaryColor 的 RGB 是相对乘色，A 不使用；SecondaryBaseColorTint 可混入 MainTex * BaseColor * 游戏三色染发后的有效发色。这是风格化双瓣反射近似，不是完整发丝散射；两瓣共同位于独立 Clearcoat 涂层之下。

UseHairHighlightMap 启用独立 UV0 局部控制图：线性 R/G 分别是以 0.5 为零点的主/副瓣有符号偏移，由 Primary/SecondaryShiftMapScale 以角度缩放；B/A 分别为主/副瓣覆盖。随包发布材质已显式绑定中性图 (0.5,0.5,1,1)。在其他材质上开启时请指定控制图：运行时未绑定的槽位按白色处理，即全覆盖、满正偏移，不会自动生成中性数据；默认关闭与零局部增益仍保证旧材质兼容。自绘图关闭 sRGB；ST 独立，但过滤与寻址复用 MainTex，请匹配图集边缘与过滤需求。蒙版只衰减对应高光，不归一化补亮、不裁切网格；SpecularMask 仍是总高光遮罩。全局与局部偏移相加后限制在 ±40°。

HairSpecularNormalInfluence 和 HairSpecularDetailNormalInfluence 分别调整已有主/细节法线对直接高光的影响，默认 1/1 复现旧路径。Base 与 ForwardAdd 中，双瓣的形状、导数 AA 和法线地平线衰减统一使用选定高光法线；被排除的法线不会再通过衰减间接压掉高光。网格朝光保护和真实投影仍保留。Toon 漫反射、探针法线、MatCap 与 Clearcoat 保留各自法线。HairEnvironmentAnisotropy=0 保留原探针反射，正值按 HairAnisotropy 和发丝轴混合弯曲反射方向。环境粗糙度独立，不增加探针采样次数，不在 ForwardAdd 重复计算环境。Unity Cubemap 的预过滤仍是各向同性，因此这是方向近似，不是双瓣各向异性 IBL 卷积。

HairHighlightDebugView：1 加权主瓣直接高光；2 加权副瓣；3 世界空间发丝方向；4 RG 显示两瓣有效偏移（0.5 为零，两端 ±40°）；5 RG 显示两瓣覆盖；6 所选高光法线。高光视图包括附加灯、位于涂层透射之前；数据视图抑制 Add；全部抑制雾和描边并保留覆盖。新增参数默认中性或关闭，不自动覆盖旧材质保存值。可选起点：主瓣偏移 -10、副瓣 +12、份额 0.35、副瓣大小 0.62、柔度 0.3、Toon 混合 0.7、粗糙度偏移 0.18、发色染色 0.35；这些只是示例参数，不是新默认值。

无贴图高光高度

HairPrimaryHeight 和共用的 HairHeightAxisAngle 位于 Hair Highlight，HairSecondaryHeight 位于 Hair Secondary Highlight。两瓣 Height 默认均为 0，范围 -1～1，直接偏置现有程序化各向异性反射框架，不采样 Gloss 图。无需定位模式开关、HairGloss 贴图、UV2、头骨绑定或新增插件。数值是无量纲的美术斜率偏置，不是距离或度数：完整 N／T 反射框架绕 cross(所选法线, 表面高度轴) 旋转 -atan(Height)。连续 GGX 与 Toon 共用偏置后的框架及内部可见性项；真实几何光线／视线保护、灯光数据、Fresnel、投影、蒙版、染色和 (1-w)／w 份额不变，所选框架导数参与法线 AA，不增加第三瓣或无光自发亮层。原角度 Shift 保留沿发丝、以度数计的含义，先执行，再施加独立的表面高度框架偏置。

HairHeightAxisAngle 是独立于发丝流向的网格切平面定位轴：90° 为网格 V，-90° 反转 V，0° 为 U，不使用 StrandAngle 或流向图。因此改变发丝方向不再改变高度控制使用哪个网格轴。两瓣 Height 均为 0 时绕过；现有主／细节高光法线用于投影此轴，不增加采样。切线随正常网格变形更新。网格 V 不保证是世界／头部／画面向上，旋转／镜像或方向不一致的发片 UV 仍需校准，不能宣称绝对头部高度稳定。借鉴 xukmi 的是简单控制体验，不是其 SpeclarHeight／UV2／Gloss 采样算法或数值兼容，不添加同名继承别名。

起始参数：PrimaryHeight=0.2、SecondaryHeight=0、HeightAxisAngle=90、主瓣 Shift=0、副瓣 Weight=0。先用 HairHighlightDebugView=1 隔离主高光，对比 -0.2／0／+0.2；方向相反时把 HeightAxisAngle 改为 -90，资产 U 才是预期高度方向时用 0。保留正确的发丝流向，不再用 StrandAngle 纠正高度方向；原 Size／Roughness／LongitudinalWidth／AzimuthalWidth 继续调形状。最后高光调试设回 0。副瓣可从 Weight=0.25、SecondaryHeight=-0.15 开始，再调原有大小和柔度。灯光和投影仍可能改变可见最亮点。

原 Head Band 实验已封存。原有九项属性仅作为隐藏的旧材质兼容占位，不再参与渲染；保存的 PositionMode=1 也不会阻止 Surface Height 生效。调试范围收回 0～6，旧值 7／8／9 回到最终画面，不再显示头骨数据。TomHairHeadBand.dll 不再构建或打包；旧测试安装中可移除这个已停用的可选 DLL，避免旧插件继续后台扫描。不要删除无关的 HairFeather、SDF 或其他配套插件。

HairFrontMode：0 关闭，1 硬 stencil，2 内侧羽化。HairFrontOpacity=1 为不透明。stencil 外仍为正常头发 cutout；改变相机侧透明度不会挖掉头发投下的阴影。

Feather Width Mode：0 像素，1 投影世界单位。像素模式保留旧材质行为；世界单位随距离/FOV/分辨率投影。宽度、Midpoint、Power 独立。过大的投影半径受提供器 256 像素预算限制，日志会标注。

眼部 writer 必须先于头发绘制。常用队列是 EyeWX 2472、EyeX 2474、HairX 2475；不要为了让某一层透出而随意打乱队列。羽化只认识受支持的 writer，并不是任意 shader 的真实 stencil 拷贝。眼白缺少支持时，眼白与瞳孔接缝可能被错误当成边界；改为受支持的 EyeWX/EyeWPlus 并检查队列。Mode 1 可作为定位辅助，但不是证明羽化整体正确。

当前羽化提供器针对单眼 D3D11 Forward；立体相机等不支持配置回退硬边。

7. EyeWX 与 EyeX

EyeWX 使用游戏 _Color 别名，0.5 为中性，再叠加 BaseColor。EyeX 保留原生虹膜旋转、表情层和高光层；这些游戏别名不应被用户手工清空。表面高光贴图和 Clearcoat 可以并存，但叠得过强会显得重复。

AlphaMask / Alpha / Cutoff 控制未偏移源覆盖；StencilCutoff 额外控制 stencil 写入。EyeWX 对通过阈值的区域按 cutout 绘制，EyeX 对存活覆盖继续 alpha 混合。光学范围、透明范围、stencil 范围是三件事。

程序化视差

EyeOpticsMode=1 开启。IrisCenterX/Y 与 IrisRadiusX/Y 定义最终 MainTex UV 中的椭圆。IrisDepthShape：0 原始平底，1 浅锥，2 浅碗。IrisDepth 是两种模式共用的全局凹陷增益，以局部虹膜半径为尺度，不是米或像素。EyeOpticsStrength=0 回到原采样。

EyeRefractionIOR 与 ClearCoatIOR 独立；增加折射 IOR 会减小横向视差，这属于当前光线路径的设计。IOR=1 去掉折射弯曲，不消除凹陷自身的视差。旧材质要复现分离前的结果，可将原 ClearCoatIOR 数值手动复制到 EyeRefractionIOR 一次；系统不强制迁移已保存材质。

自绘深度与范围

UseEyeSurfaceMask=1 后，贴图替代程序化椭圆边界和 EdgeFade；与主虹膜贴图及其旋转/ST 对齐。

EyeSurfaceMapMode 定义 无效果区域
0 灰度高度 白=表面/零深度，黑=最深；忽略 A 涂成白色
1 R 深度 + A 范围 R 白=最深、黑=零深度；A 白=范围内 A=0，并在边缘平滑过渡

两个模式都乘 IrisDepth；半径在贴图模式仍作为深度/位移尺度标定，但不再裁剪自绘区域。A 只影响深度和进入过渡，不改变表面透明度。

适合：平底浅凹、浅锥、浅碗、平滑单值灰度场。不要将绘画高光直接转换为深度，更不要把眼睛颜色亮暗当作几何高度。避免陡直坑壁、高频噪声和多层回折表面。

EyeOpticsMaxOffset 限制极端位移；EyeUVMin/Max 是安全图集边界。偏移采样超出安全区域或几何条件失效时会回到原 UV，所以不能只靠无限拉大强度获得深洞。

色散与角度

EyeDispersion=0 单路，正值采用三条 RGB 光线的几何近似。它不是波动光学，不会把整个涂层变成彩虹。通常只在高对比边缘和斜视时较清楚。

测试角度时要真正改变相机相对眼表面的方向；仅移动构图或使用始终朝向相机的眼球，差异可能很弱。先用明显纹理与浅锥/浅碗测试，再逐步调整 Depth、IOR、最大偏移和安全范围。

当前不是 POM，不保证近侧坑壁挡住远侧内容。以后确实需要这种自遮挡时，再考虑 POM / 首次可见交点搜索；角度差异不够强本身不是必须升级的理由。不需要额外角膜网格。

保留已正确绑定的游戏／自绘贴图。只有对应槽确实为空时，才在 ME 中导入配套中性数据 PNG：

  • SkinControlMap：Material/SkinControlNeutral.png，RGBA (1,1,0,1)；柔化与暖色 继续由滑条控制，自绘湿润区域为零，A 不使用。

DetailNormalMapScale 还参与游戏内部线条/画入阴影；SkinDiffuseNormalDetail 只减弱漫反射细节，保留高光/涂层细节。SkinStrength / Wrap / Warmth 提供前侧柔化和明暗交界暖色，不是屏幕空间或体积 SSS，也不会穿透外部遮挡。

SpecularPower / SpecularPowerNail 保留游戏皮肤与指甲/嘴唇的光泽增益；SkinGameGloss 控制参与度。它们不等于 Roughness，也不自动调 Clearcoat。SkinPatternStrength / notusetexspecular 控制移动的画入高光遮罩。

独立绘制阴影颜色

SkinX 与 SkinXTess 将绘制阴影和投影区域染色分开。ME 的 Skin Response 分类中，SkinShadeStrength、SkinShadeColorSource、SkinShadeColor 相邻排列。SkinShadeColorSource=1（Independent）时，使用 SkinShadeColor 的 RGB 调整 DetailMask G / LineMask B 共同形成的绘制阴影，强度仍由 SkinShadeStrength 控制。颜色 A 不参与计算，不是透明度或第二个强度。两路蒙版维持原有合并规则，不叠加两层阴影。染色作用于 Base/Add 及间接光、补光中的皮肤漫反射，不直接染高光、涂层或液体反射瓣。

ShadowColor 保留共享基线职责：主光投影区域的 Base 间接漫反射染色。SkinLineColor 独立控制内部描线；ToonShadeColor 仍是可选的主光驱动彩色补光，不是所有阴影的总调色。ToonMinLighting 保持 0.15。

兼容方式：着色器的 SkinShadeColorSource 默认 0（FollowShadowColor），保留没有新字段的旧材质及运行时新建材质的效果；此时忽略 SkinShadeColor，绘制阴影继续跟随 ShadowColor。两份发布载体预设采用 Independent，并复制原 ShadowColor 的 RGB，保持起始外观。旧人物卡切换时，先把原 ShadowColor 复制到 SkinShadeColor，再将来源设为 1；不会自动迁移游戏人物卡或覆盖已保存参数。

可选面部 SDF

SkinX 与 SkinXTess 支持独立的面部 SDF 阈值图。开启 UseFaceSDF 和 UseRamp，将贴图放入 FaceSDFTex，用 FaceSDFMask 的 R 限定脸部区域。FaceSDFStrength=0 或区域蒙版为黑时恢复法线驱动的 Toon。开关默认关闭，身体和已有脸部材质保留原设置。DetailMask 仍按原定义使用，不能直接当 SDF 图。

两张贴图均按线性数据导入（关闭 sRGB），不设为法线图。使用 UV0，各有独立缩放/偏移，共用双线性、Clamp 采样。阈值图数值越高，灯光转到头后方时越晚进入暗部。FaceSDFChannel 选择 R/G/B/A；FaceSDFInvert 反相。左右模式：0 Single 两侧都读取指定通道；1 MirrorU 在头部左侧来光时，将 SDF ST 后的 U 绕 FaceSDFMirrorU 镜像（默认 0.5）；2 RGPair 右侧读 R、左侧读 G，不镜像且忽略通道选择。区域蒙版始终不镜像。

FaceSDFAngleMode=0 为余弦编码，阈值=(1-正面余弦)/2；1 为角度编码，阈值=相对头部的水平夹角绝对值/180 度。二者正面阈值为 0、侧面 0.5、背面 1，应按资产制作约定选择，不能自动识别任意导入 SDF。FaceSDFOffset 为阈值偏移，正值扩大暗部；FaceSDFSoftness 控制边缘宽度，ToonAA 补充像素抗锯齿。原有主/次 Ramp 的端点决定两侧亮度，不重放贴图 Ramp 中间的多级色阶。SDF 区域替换法线 Toon 分界及其漫反射地平线限制，随后仍应用真实投影。ToonMinLighting 保持 0.15。

FaceSDFDirectionSource=0 使用 Renderer 物体轴；1 使用可选 TomSkinSDF.dll 的头骨方向，没有有效跟踪数据时退回物体轴。将 DLL 放入 BepInEx/plugins 后，可跟随 KKS 头骨或 Humanoid Head 骨骼；不需要额外 AssetBundle，也不改写材质设置。FaceSDFForward / FaceSDFUp 的 XYZ 为局部前方/上方，默认 +Z/+Y，W 不用；ME 将向量显示为颜色栏位，但它们不是染色。朝 -Z 的导入脸可使用 Forward=(0,0,-1,0)。跟踪模式的局部轴属于头骨，不属于 Renderer；未识别的自定义骨架需在 Unity 中显式绑定 TomSkinSDFHead.head。正上/正下方来光没有确定左右方位，会平滑退回法线明暗。

SDF 仅改变 Base/Add 的直接 Toon 漫反射，高光、SH、Clearcoat、液体法线、网格裁剪和投影生成沿用现有路径。它不能区分自投影与头发、手或衣物投影。FaceSDFDebugView：1 有效区域，2 选定数据乘区域，3 主光在真实投影之前的亮区；最终显示设为 0。数据视图关闭附加灯、描边和雾的输出。

液体与湿润

SkinX、MainOpaqueX、三个 Alpha 变体及其已有 Tess 衍生版共用同一液体层；独立 tom/LiquidX 使用相同核心，可作为材质复制叠加层或独立薄液面。HairX、EyeX、EyeWX 不加入。沿用 0.3.1 已发布的现代液体系统，不提供切回更早实验算法的开关。

LiquidCoverageMode：0 游戏五部位，1 自绘蒙版 R，2 整面覆盖。游戏模式使用 liquidmask 的 RGB 组合与 liquidftop/fbot/btop/bbot/face 五个 0..2 数量；Texture2 的 R 在 0..1 出现，G 在 1..2 与第一阶段取 max 并集。模式 1 使用 LiquidCoverageMap。以上是最终渲染槽，不是游戏合成器的同名输入；shader 不会补齐缺失贴图，也不会自动给任意物体更新游戏液体量。

LiquidCutoff 默认 0.02，清除过低的图案/自绘蒙版数值并重映射剩余范围；LiquidEdgeSoftness 默认 0.04，提供带像素过滤的柔边。清理在部位数量混合之前进行，避免数量动画突跳。同一覆盖率控制染色、液体法线和所有湿润反射，但不裁掉网格。SkinLiquidMaterial 是整个液体层的总强度，0 完全恢复干燥材质。

Texture3 是切线法线，不是高度图。LiquidNormalEncoding：0 Raw AG 读取 GPU 数值 A=X、G=Y，保留游戏运行时纹理采样标志；1 Exported AG PNG 仅对经过 sRGB 编码的 G 做反转换，Alpha 保持数值，要求数据采样（关闭 sRGB）；2 Unity Normal 用于通过法线导入器导入的普通法线。模式 1 不可再叠加自动 sRGB 解码。根据输入链路选择，不要只凭灰度外观判断。随包中性 AG 法线对应模式 0；其他模式未指定法线时，将 SkinLiquidNormalScale 设为 0。

LiquidTiling 虽然在 ME 显示为颜色栏，实际为原始向量：R/G 是偏移，B/A 是缩放，默认 (0,0,1,1)。先应用它，再应用图案、法线、自绘蒙版各自的 ST；这三类纹理使用 repeat/trilinear/aniso8 采样，不做破坏导数的 UV 取余。部位蒙版使用独立 ST 与 linear-clamp 采样，不跟随液体平铺。图案/部位/自绘覆盖均按线性数据处理，不要给 LiquidTiling 做颜色 gamma 变换。

SkinLiquidNormalScale 缩放解码后的坡度，再归一化并平滑限制倾角；LiquidMaxNormalAngle 默认 60 度，相对于底层主法线。LiquidNormalAA 默认 1，对无法分辨的法线细节做高光抗锯齿。先确认编码，再调强度，不要用高粗糙度掩盖错误方向。LiquidDiffuseNormal 仅影响液体染色的明暗，默认 0，不再推动皮肤或衣物的硬 Toon 阴影。

液体是底材上唯一的介质湿润界面，使用物理 GGX 和近似透射。LiquidIOR 默认 1.33，正入射反射率约 0.02；1 消除界面反射。SkinLiquidRoughness、LiquidSpecularStrength 不受底层 Toon 高光、干燥蒙版、皮肤/指甲光泽控制。LiquidEnvironmentStrength 独立控制探针反射，不要求底层 ReflectionMode 开启。环境/间接光仅在 Base 中计算，直接光在 Base/Add 中遵循每盏灯、cookie 和物理阴影。高光增益属于艺术控制，不保证物理能量守恒。

LiquidEnergyBlend 默认 0.25，控制底材衰减，也包括折射率匹配带来的底材高光减弱。0 保留底层光照，1 使用完整的近似界面衰减，但不改变液体自身的 GGX 高光和探针反射。LiquidAttenuationNormal 默认 0，单独控制液滴细节对透射法线的影响：0 使用底材主法线，避免细小坡度在底色上刻出暗沟；1 启用完整液体法线。反射始终保留完整液体法线。这两项不取消真实投影，也不关闭液体层。低 Energy Blend 是不严格守恒的风格化选择，本功能不是完整折射光路模型；湿润区域仍会替代公共 Clearcoat。

SkinLiquidColor 的 RGB 是染色，A 乘 SkinLiquidColorStrength 是染色不透明度。A=0 的透明水膜保留底色和 Toon 明暗，但仍有界面衰减和反射。有色液体使用独立的柔和漫反射；LiquidToonBlend 可将其混向底层 Toon 明暗。液体 GGX 高光本身始终非 Toon。

LiquidShadowColor 是可选的液体染色暗部调色：RGB 为限制在 0..1 的乘算色，A 为混合强度，默认 0。它作用于每盏灯的染色直接光和 Base 中的染色间接光，随染色不透明度淡出；SkinLiquidColor A=0 或 SkinLiquidColorStrength=0 时完全消失。它不染透明反光、不改变干燥皮肤、不添加自发光补光，也不替代真实阴影。透明水膜过暗应调 LiquidEnergyBlend/LiquidAttenuationNormal，不是这个颜色；整层一起淡出则使用 SkinLiquidMaterial。

液体覆盖区域替代公共 Clearcoat 顶层，不再叠加第二次涂层反射；范围外保留公共涂层。SkinCoatCoverage、SkinWetness、SkinLiquidCoatNormal 仍控制公共涂层，但不会再产生第二个液体界面。集成路径不改变网格 Alpha、裁切、描边、深度或投影覆盖；Alpha 材质中完全透明的像素仍不可见。

给其他材质叠加 LiquidX 时，使用 UV 对齐的材质复制槽或复制网格，选择自绘或游戏模式，并复制需要的图案、法线、部位纹理。MainTex A 与 AlphaMask R 可匹配底材裁切；不需要裁切时使用白色输入。默认深度偏移 Units=-1，用于减轻共面冲突。独立薄液面使用整面或自绘覆盖，并将两个深度偏移都设为 0。LiquidX 默认染色 A=0，采用预乘透明混合，不写深度、不投不透明阴影；可接收光照、阴影与探针反射。

叠加 helper 无法改写未知底材的 BRDF，使用帧缓冲混合近似透射；集成路径才能按底材计算界面衰减。LiquidEnergyBlend 和 LiquidAttenuationNormal 同样控制 helper 对背景的压暗，阴影色则只影响它自身的染色部分。不要在已启用集成液体的表面再叠 LiquidX。本功能是薄表面着色，不是水体体积模拟：没有 GrabPass、场景折射、厚度吸收、波浪、流体模拟或无序透明。透明排序与相交面仍受 Unity 常规限制。

LiquidDebugView：1 有效覆盖，2 覆盖内世界法线，3 液体直接高光，4 液体环境反射，5 染色不透明度，6 清理前原始覆盖；0 返回最终效果。首先检查干燥区域在覆盖视图中为黑，并在切换 SkinLiquidMaterial 时保持不变。

9. Reflection Probe 与 SH Volume

在工作室 Tom Lighting > Probes 添加物品，通过 ME 编辑其控制材质。256/512/1024 或不同 SH 网格是起点，不是锁定版本；无需删物品重导。参数由插件读取，shader 本身不执行捕捉。

常用控件 含义
ProbeEnabled / Intensity 启用与贡献强度；强度变化不重捕捉
ProbeRefresh 0→1 或 1→0 都请求一次；保持 1 不会每帧刷新
ProbeRefreshScope / Group 范围 0 自己、1 同组、2 全部；Group 为整数
ProbeUpdateMode 0 加载、1 位置变化、2 定时、3 手动
ProbeCaptureOnLoad 初次或重新启用时捕捉，与上述模式独立
ProbeInterval 请求间隔秒数；RP 最小 0.5，SH 最小 5，不保证这时已捕完
ProbeSize / Offset X/Y/Z 世界轴对齐范围与偏移，使用这些参数而非缩放/旋转物品
ProbeNearClip / FarClip 六个面各自的裁剪平面；NearClip 不是球形排除半径
ProbeCapturePreset 0 环境层，1 含角色，2 自定义 32 位 layer mask
ProbeQuality RP：0=256、1=512、2=1024，每个 cubemap 面
SHGridX/Y/Z 每轴 2–8，总采样点是三者乘积
SHCaptureQuality 0/1/2/3 分别为每面 8/16/32/64
SHSamplesPerFrame 每帧请求 1–4 点，同时受插件全局预算限制

RP 提供镜面环境反射；SH 提供低频方向性漫射，不能替代尖锐高光或实时阴影。自定义 SH 一次为一个 renderer 选择一个体积，依据 bounds 中心、优先级与边缘权重；不是多个体积的逐像素混合。

捕捉方向保持世界轴，不随物品旋转。父对象旋转若改变物品世界位置，仍会造成真正的位置变化。近裁剪只能裁近处几何；要避免角色自捕捉，优先检查捕捉层。被放到特殊层的角色不保证由环境预设自动排除。

共用队列每次只做一个捕捉任务；同组刷新先 SH 后 RP。SH 刷新完成并重新绑定前保留旧 atlas 与匹配的范围；首次没有历史结果时走内置间接光。RP 更改分辨率/HDR 时会重建内部 helper，期间可能回退其他探针/天空。

捕捉结果不随场景持久化，只保存参数；重新加载需要重捕捉。SH 每个采样点渲染六面并同步读回，分帧不是免费异步 GI；复杂场景仍可能卡顿。RP 需要 Unity 的 Realtime Reflection Probes 质量选项，插件不会擅自修改全局质量。

12. 独立细分与真实位移

主动选择 tom/MainOpaqueXTess、tom/SkinXTess 或 tom/MainAlphaXTess。继承属性的命名、裁剪、光照、液体、Clearcoat 与投影行为均与普通版一致；SkinXTess 同时保留 Face SDF、UV0-UV3 和顶点色叠加层门控。切换 shader 时仍依赖 ME 保留已保存的数值。仅支持 D3D11 / shader model 5，不静默回退到缺少功能的版本。普通版不包含 Hull/Domain 阶段，才是完全不付细分成本的选择；Tess 版倍率为 1 仍调用细分阶段。

参数 定义与默认值
TessellationMode 0 固定倍率，1 屏幕边长自适应；默认 1
TessellationFactor 细分上限 1..16，默认 4；脚本传入超范围值也会限制
TessellationEdgeLength 屏幕边长目标 4..64 像素，默认 16；越小越密，仍受倍率上限约束
TessellationSmooth Phong 曲面平滑 0..1，默认 0；独立于细分密度和高度
UseGeometryMask / GeometryMask 默认关闭；线性 RG：R 平滑、G 位移，B/A 不使用；白色允许两者，黑色保留原表面
DisplacementMap 线性 R 高度，不是法线贴图；使用 UV0，独立平铺和偏移
DisplacementStrength 有正负的世界空间尺度 -0.05..0.05，默认 0
DisplacementMidlevel 零高度参考 0..1，默认 0.5
DisplacementMip 高度图／几何蒙版显式 mip 0..8，默认 0；远景或噪声细节可调高
DisplacementNormalStrength 高度梯度法线修正 0..1，默认 1；0 保留插值网格法线
TessellationBoundsPadding 可选辅助组件额外扩展的世界空间包围盒余量 0..0.1，默认 0；不移动几何

位移为 (saturate(R) - Midlevel) * Strength * mask.G，沿插值后的世界空间法线移动。例如白图、Strength=0.02、Midlevel=0.5 向外移动 0.01 Unity 世界单位。打包材质显式绑定精确线性 0.5 中性图。代码中直接新建材质时，应先绑定高度图再开位移，不能依赖引擎内置 gray 恰好中性。两张数据图都需要关闭 sRGB，ME 运行时导入也必须是数据采样。GeometryMask 独立使用 UV0 平铺和偏移；R 不控制细分密度，G 不改变干燥材质覆盖率。

先将平滑、位移保持为零检查原外观，再分别增加密度、平滑和高度。颜色、ForwardAdd、轮廓、ShadowCaster 和 MainAlphaXTess 的可选深度预写使用同一变形，不通过 patch 视锥／背面剔除丢弃镜头外的投影物。屏幕边长模式的密度随视角变化，需要可复现拓扑时使用固定模式。单纯增加三角形不能恢复缺少的形状。高度法线是浅层梯度近似，不包含精确曲面法线传输或自相交处理。

MainAlphaXTess 保留直通／预乘 AlphaBlendMode、全局 Alpha、可选颜色裁剪／ZWrite、DepthPrepass（默认关闭）、DepthShadowCutoff 和 CastShadows。深度与投影覆盖仍使用原 Alpha 规则，细分不会让半透明表面获得物理透射阴影。深度预写写入的是变形后表面，而不是原网格；细分不解决透明排序或网格交叉。本次不新增 BackFront、旧 2Pass、Hair、Eye 或 Liquid 的 Tess 入口。自动扩展 MainAlphaXTess 包围盒需使用 Tessellation Bounds 0.1.1 或更新版，替换旧 DLL，不要同时安装两份。

通过片元裁剪停用的 Pass 功能仍可能执行几何阶段，包括 DepthPrepass=0；这类开关不保证该 Pass 的细分成本归零。完全移除细分阶段仍需选择普通 shader。

包围盒支持：可选安装 TomTessellation.dll 到 BepInEx/plugins/TomShadersX，无需额外 helper AssetBundle；Unity 中可给 renderer 添加 TomShadersX.TomTessellationBounds。Shader 不依赖它才能渲染，但没有扩展 CPU 包围盒时，Unity 可能提前裁掉位移／平滑后的几何或投影。组件扩展 SkinnedMeshRenderer.localBounds；MeshRenderer 使用只修改 bounds 的私有 mesh 副本，不修改原共享网格。停用时恢复自己拥有的改动，并保留外部替换的网格／包围盒；与任意同时改写 mesh 的 mod 配合仍需验证。游戏插件约每秒发现一次活跃 Tess renderer，已附加组件每次 LateUpdate 更新包围盒。其 CPU 扫描和静态网格副本成本与细分 GPU 成本分开计算。

不会自动焊接 UV 接缝、分裂法线、头身连接或不同材质。相邻边的高度与法线应一致，可用几何蒙版黑边保护接缝；突变仍可能开裂。平滑包围盒采用保守扩展，可能较宽。GPU 变形不修改碰撞体或 CPU 顶点。额外三角形、高度／梯度采样和多灯几何 Pass 需要按场景／设备实测，本次不认证全角色性能。若使用头骨方向 Face SDF，需升级到能识别 SkinXTess 的可选插件 0.1.1 或更新版。
